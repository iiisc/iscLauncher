## 1. Fonts (download free, OFL licensed)

| File | Source | Used for |
|---|---|---|
| `Cinzel-Bold.ttf` | Google Fonts → Cinzel | All headings, labels, buttons |
| `Cinzel-Regular.ttf` | Google Fonts → Cinzel | Section labels, secondary headings |
| `CrimsonPro-Regular.ttf` | Google Fonts → Crimson Pro | Descriptions, subtitles, flavor text |
| `CrimsonPro-Italic.ttf` | Google Fonts → Crimson Pro | Italic body text |
| `DMSans-Regular.ttf` | Google Fonts → DM Sans | Settings keys, version strings |
| `DMSans-Medium.ttf` | Google Fonts → DM Sans | UI label medium weight |

Place in: `Assets/Fonts/`

**Note:** Only fonts are essential for the visual overhaul. Other assets below are optional enhancements.

## Asset Production Tips

**Font download:** Go to fonts.google.com, search each font name, download the TTF files.

**Decorative elements:** Create simple gradient rectangles in any image editor (GIMP, Photoshop, or Paint.NET).
